# Windows M5 按键映射与配置控制台

## 模块目标

[用户确认] 在 Windows 2.4G 接收器场景下识别 M5 Keyboard，支持按键单击/双击映射，并提供接近参考图的设备管理网页配置界面。完成标准：Windows 端读取稳定配置；网页能编辑并导出配置；真实 M5 正面和背面按键热区可操作。

### 已完成

- [代码证据] 2.4G 接收器识别为 `VID_3554&PID_FC03`，M5 Raw Input 接口识别为 `VID_1915&PID_1025`。
- [代码证据] `Tools/windows-raw-input-probe/Program.cs` 已支持 Raw Input、`VK_BROWSER_HOME` 拦截、复制/粘贴手势和配置驱动动作。
- [代码证据] `Tools/windows-raw-input-probe/keymap.json` 与 `MappingEngine.cs` 已加入配置结构。
- [代码证据] `docs/index.html`、`docs/app.js`、`docs/styles.css` 已加入网页配置控制台；可编辑单击/双击并下载 `keymap.json`。
- [代码证据] `docs/assets/remotes/m5-keyboard.jpg` 已加入用户提供的 M5 设备图。
- [代码证据] 相关提交已推送：`66e23a3`、`e0ca09f`、`6522b38`、`a7246d2`、`ba339df`。

## 继续入口

停止点：先校准网页中 M5 正面/背面的热区位置，再处理 Windows 配置自动加载。

下一步可执行动作：打开 `docs/index.html`，分别切换“遥控器正面”和“背面键盘”，记录每个热区偏移并修改 `docs/styles.css` 中 `.hot-*` 的位置。

阻塞：当前没有已知代码阻塞；真实热区坐标需要用户在本地浏览器中目视确认。

验证命令：

```powershell
node --check docs/app.js
git diff --check
```

可观察结果：网页切换正面/背面后显示对应设备裁剪图；热区默认不可见，悬停时显示边框；点击热区后右侧映射列表滚动到对应按键。
